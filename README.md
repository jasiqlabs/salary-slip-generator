# Public Salary Slip Generator

This project is a public salary slip generator for JASIQ Labs. It is built with React and Vite for high performance, styled with Tailwind CSS, and uses html2canvas and jspdf for client-side PDF generation.

## Features
- Split-screen layout with form input and live preview
- Dynamic form with company info, employee info, earnings, and deductions
- Real-time calculations of gross salary, deductions, and net pay
- Export options: download PDF, send via email, share on WhatsApp
- Mobile responsive design

## Tech Stack
- React + Vite
- Tailwind CSS
- Axios
- html2canvas
- jspdf
- lucide-react (icons)

## Folder Structure
- `src/components` - React components (Form, Preview, Header)
- `src/utils` - Utility functions (Calculations, CurrencyConverter)

## Getting Started
1. Install dependencies
2. Run the development server
